# Figma prototype handoff

**Figma prototype (Home start):** https://www.figma.com/proto/V308ixIbOMxorLpHzL4pPh/RCOEM-Campus-Event-Portal-%E2%80%94-Nagpur?node-id=2-2&t=MZHfsX3BLS4bFt4k-1&starting-point-node-id=2%3A2

The file contains four 1440 × 900 screens: Home, All Events, Event Details, and Register. Navigation links connect the main flow, and Home is the flow starting point. Present the file in Figma to demonstrate the prototype.

## RCOEM branding

The Figma canvas and the included HTML/Bootstrap project use RCOEM Nagpur branding. The four-screen prototype is ready to present.

## Browser demonstration

Open `index.html` in a browser, then demonstrate the Home call to action, event category filters, event details, and registration confirmation. Registration is a front-end demonstration and is not sent to a server.
