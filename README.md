# RCOEM Campus Event Portal — LA-II

A responsive campus event discovery and registration site built with HTML, Bootstrap 5, CSS, and a small amount of JavaScript.

## Project contents

- `index.html` — home page and featured event
- `events.html` — event cards with working category filters
- `event.html` — CodeSprint details and schedule
- `register.html` — registration form with client-side confirmation
- `css/style.css` — shared visual styles
- `design/figma-design-board.svg` — visual screen board, ready to import into Figma
- `FIGMA_HANDOFF.md` — Figma file link and prototype handoff

## Run in a browser

Open `index.html` directly. Bootstrap and Google Fonts load from their CDNs, so an internet connection is needed for those external assets. Navigation links work between the local HTML files. On the All Events page, select a category to filter the cards; on Register, submit the form to see the confirmation state.

## GitHub submission

Create a public repository named `campus-event-portal`, upload the contents of this folder, and paste the repository URL in Google Classroom (GC). Use `https://github.com/<your-username>/campus-event-portal` as the link format.

## Design summary

The portal helps students discover campus events, check details, and register. Navy provides a strong institutional base; teal marks primary actions; amber highlights dates and featured content. Bootstrap's responsive grid adapts the cards and navigation to smaller screens.
